第五輪複審與我方校驗對 v5 的判定：**三面架構成立、⑥a′ 是五輪以來最乾淨的設計、⑦ 參數兩輪獨立驗算一致（可照案落地）**。
但 Phase 1（節流，第一個動工的 Phase）有兩個照做就炸的缺陷，經校驗全部證實，v6 據此修訂實作敘述：

1. **阻斷一（seg_gap）**：v5 的 1.1 寫「移除 `DEFAULT_SEG_GAP` 與 seg_gap 邏輯」——但該常數被
   [`scan_probe.py:41`](../../../script/scan/scan_probe.py#L41) 與 [`scan_run.py:116`](../../../script/scan/scan_run.py#L116)
   的 argparse default 引用（另有六處呼叫傳 `seg_gap=args.seg_gap`）。刪除常數 → 兩支工具執行 main() 時 AttributeError
   （校驗更正：爆點是 **main() 執行時**，非複審所說的 import 階段；「CI 抓不到」前提證實——測試不 import 這兩支）。
   **v6 採方案 B：常數保留、預設改 0.0、docstring 註明停用**——CLI 完全相容、`seg_gap=0` 時加成為零、不違反邊界宣告。
2. **阻斷二（enumerate）**：v5 的 1.2 只標了 alive 迴圈的 enumerate，實際**四處迴圈頭都沒有 `i`**
   （[daily.py:178](../../../script/scan/daily.py#L178)/229/324/365）——照做會 NameError。
   **且複審的補法本身有坑**（校驗更正）：explore/sample 的 `fresh`/`hits` 是 **rec dict 清單**，
   直接傳 `sleep_scan` 會在 `codes[index][:2]` 處 **KeyError**（`d[:2]`＝以 slice 物件當 key 查找）——
   **v6 補法：四處全部 enumerate，explore/sample 先建字串清單** `[r["code"] for r in fresh]`／`[r["code"] for r in hits]` 再傳。

三個次要一併併入：⑧ 的 else 分支只有 `COUNT`（`--jq 'length'`），**comment 需要 issue number**——
改查 `--jq '.[0].number'`（v6 的 5.3）；白名單長期風險在「增長切割名單」——**⑥b 的計數基準是 alive 清單
（dead 碼不打 step2_of），今日三段 306/312/4（非複審的 6）**，補監控指標；⑦c 補「enrich 不適用」說明；
test_pacing 補 patch 自動還原方式。confirm 總長校正：**65 分為估算值，實測 70-75 分，Phase 7 校正**。

### ⑥b 在五個迴圈的實際覆蓋範圍（校驗修訂，採納第六輪）

N=3 的熔斷門檻需要「連續 3 碼解析失敗」。各迴圈的可打 `step2_of` 碼數決定它能否觸發：

| 迴圈 | 可打 step2_of 的碼數 | ⑥b 有效 | 說明 |
|---|---|---|---|
| alive（confirm） | 625 | ✅ | 主要防線，分母充足 |
| dead（confirm revive） | 2（今日 16311／16312） | ❌ | 分母 < 3；且需 `m1_success=True` 才進 revive 分支 |
| explore（fresh） | 1,385 個潛在碼位（fresh 通常數十） | ✅ | 分母充足 |

**對 Phase 8 的意義**：若真發生整站忙碌頁，預期熔斷點在 **alive 或 explore** 階段，不會在 dead／sample。
這兩個迴圈的 ⑥b 保留同形但不具實際防護作用。**對 sample 的補充**：sample 的 M1 階段（`probe_batch`）
已有熔斷保護（403/429 → blown），所以 sample 不是完全無保護——只是其 step2 階段的 ⑥b 無效。

## 研究方法

以唯讀方式分七步定案（1-6 承 v3-v5，7 為量化驗算法）：

1. **行為對照法**；2. **注入驗證法**；3. **最小修改原則**（每處獨立可回滾）；4. **落點貫通性檢查**；5. **測試證偽力檢查**；6. **真實鏈路探針法**（驗證前提時不得 mock 被驗層）
7. **量化驗算法**：節流/密度類修改先以 log 時間戳重算、對提案參數做估算表，落地前有數字對照——
   ⑦ 的參數已經兩輪獨立驗算一致（第四輪複審與我方校驗各一次，逐位吻合）。
