### src/lib/filter.ts

在 [`supportsOrderType`](../../src/lib/filter.ts#L45-L51) 之後、`filterCoupons` 之前新增：

```ts
// 搜尋索引：name＋description＋code＋items 候選品名。外部碼多為 description=None、
// 內容只在 items（26821 型）；code 進索引是因部分券 name 不含 5 位碼（如 93014）。
// WeakMap 懶快取：每券物件只組一次，之後每鍵零重建（exp_prob/2026-10-26 bench_search.mjs 實測）。
const haystackCache = new WeakMap<Coupon, string>();

function haystackOf(c: Coupon): string {
  let h = haystackCache.get(c);
  if (h !== undefined) return h;
  const parts = [c.name, c.description ?? "", c.code ?? ""];
  if (c.items) {
    const seen = new Set<string>();
    for (const it of c.items) {
      if (it.text && !seen.has(it.text)) seen.add(it.text);
    }
    for (const t of seen) parts.push(t);
  }
  h = parts.join(" ").toLowerCase();
  haystackCache.set(c, h);
  return h;
}
```

[`filterCoupons` 現行 L62-66](../../src/lib/filter.ts#L62-L66) 的搜尋條件：

```ts
    if (terms.length > 0) {
      // 代碼也進搜尋索引：部分券的 name 不含 5 位碼（如 93014「大比薩分享餐$399」）
      const haystack = `${c.name} ${c.description ?? ""} ${c.code ?? ""}`.toLowerCase();
      if (!terms.every((t) => haystack.includes(t))) return false;
    }
```

改為：

```ts
    if (terms.length > 0) {
      if (!terms.every((t) => haystackOf(c).includes(t))) return false;
    }
```

設計要點：

- `haystackOf` 不 export——模組私有，對外 API（`filterCoupons` 等）簽名不變，[`App.tsx`](../../src/App.tsx#L93-L101) 呼叫端零改動。
- 券內品名以 `Set` 去重再拼接（同券多組重複「可樂」只進一次）。
- `it.text` 為必填 `string`（[`types.ts:MealItem`](../../src/types.ts#L8-L27)），`if (it.text)` 只擋空字串。
- `group=add` 的加購物已由 [`compact_coupon_items`](../../script/lib/coupons.py#L82-L92) 在產出端排除，不會進入搜尋——無需前端再過濾。

### src/lib/filter.test.ts

在 [`filterCoupons` describe](../../src/lib/filter.test.ts#L36) 內補 5 案例（檔頭加 `MealItem` 型別 import；`mk()` 不動）：

```ts
const mi = (text: string): MealItem => ({
  text, group: "second", groupIdx: 1, priceAdd: 0, flavorIdx: null,
});
```

1. **items 命中——26821 型**：券 `description: null`、items 含「黃金雞軟骨(小份)」，搜「雞軟骨」命中；同 describe 既有 fixture（無 items）同詞不中作對照。
2. **跨欄位 AND**：一詞只在 name（「大比薩」）、一詞只在 items（「薯金幣」），`q="大比薩 薯金幣"` 命中該券、缺一詞不中。
3. **offline 殘影的 items 也搜得到**：`status: "offline"`＋items，搜品名命中（排序恆後由既有 sortCoupons 案例覆蓋，此處只驗 filterCoupons）。
4. **快取冪等**：同一 list 連續兩次 `filterCoupons` 結果一致（第二次走 WeakMap 命中）。
5. **空 items 邊界**：`items: []` 視同無 items，仍可搜 name/description/code（既有案例的 `mk()` fixture 無 items 欄，此案例補顯式空陣列）。

既有 12 案例（含 93014 code 搜尋、殘影卡參與篩選）期望值不變——本修只增命中不減命中（items 為追加欄位）。
